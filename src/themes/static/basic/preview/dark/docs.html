Documentation

Basic picks up a site the moment you push. This page covers the shape of a project — install the CLI, add a config file, and watch your first page publish.

npm install -g basic-cli
basic init
basic publish

Installation

Basic ships as a single CLI binary with no runtime dependencies. Install it globally, then run basic init inside any project directory to generate a starting theme config.

Quickstart

A default basic.yml detects your pages and asset folders automatically. Push a change and Basic opens a preview within seconds — no dashboard clicking required to see your first live page.

Configuration file

Every site is described in basic.yml at your project root. Pages render in the order they're declared unless you mark them for a custom route, and any page can reference shared sections from your theme.
