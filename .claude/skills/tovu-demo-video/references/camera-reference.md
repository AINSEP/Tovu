# Reference camera notes (1-fps sheets: reedit/ref-v1-sheet.png, ref-v2-sheet.png)

Both references: 1440x900, 25 fps, ~30 s. Pattern per second:

## v1 contact page (29.8 s)
| t (s) | Framing | Zoom |
|---|---|---|
| 0–0.5 | Wide establishing (Pages list + chat panel) | 1.0 |
| ~0.5–1.3 | Smooth ramp into the composer (bottom-right) | 1 → 2.3 |
| 1–6 | Composer held, prompt typed live, text large and readable; frame drifts down with the growing textarea | ~2.3 |
| 6 | Send; composer empties | 2.3 |
| 7–9 | Pan up to the chat: dark user bubble + first tool-call rows ("Search tools…", "Describe tool…"), following rows down as they append; working time sped up (~20-40 s → ~3 s) | ~1.8 |
| 10–14 | Wide: reply text + new page row in the list (context beat, the only long wide) | 1.0 |
| 15–22 | Cut to the public page, zoomed on the form, fields filled live (Name/Email/Message, Send, "Thanks") | ~1.6 |
| 22–23 | Brief wide of the page / forms list | 1.0 |
| 24–29 | Form builder, then Submissions row (the result), mildly zoomed | ~1.2–1.4 |

## v2 AI images article (30.8 s)
| t (s) | Framing | Zoom |
|---|---|---|
| 0–0.5 | Wide establishing (Posts list + chat) | 1.0 |
| 1–6 | Composer, prompt typed | ~2.3 |
| 7–12 | Chat bubble "Thinking… 0 s/1 s/2 s" then tool rows, camera slides down as rows append | ~1.8 |
| 13–20 | Wide: chat streams the tool list / reply (sped up) | 1.0 |
| 21–24 | Media library: new images appear | ~1.0–1.2 |
| 25–27 | Article hero + title, large | ~1.6 |
| 28–29 | Scroll to body text + inline image | ~1.6 |

## Rules taken from it
- Wide only as 0.5–1 s openers or short context beats between zoomed passages.
- Moves are ~0.8–1 s smoothstep ramps; holds ≥ 1.5 s.
- Typing at 1x; working time compressed into 2–4 s while the camera follows new rows.
- Result moments (form filling, hero image) at 1.6–1.8x so body text is readable.
