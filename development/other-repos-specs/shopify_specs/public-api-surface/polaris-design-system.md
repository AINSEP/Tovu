# Shopify Polaris React Overview

## What It Is
Polaris is Shopify's design system for React, though it's noted as deprecated in favor of Web Components. It provides a comprehensive toolkit for building Shopify admin interfaces.

## Core Components

The system is organized into four main resource categories:

1. **Foundations** – "Fundamental design guidance for creating quality admin experiences"
2. **Components** – "Reusable elements and styles, packaged through code, for building admin interfaces"
3. **Tokens** – Coded design decisions covering color, spacing, typography, and additional properties
4. **Icons** – Over 400 icons emphasizing commerce and entrepreneurship themes

## Additional Resources
The platform includes patterns, version guides, contribution guidelines, and tools for developers. A notable announcement highlights the release of Polaris Web Components as a newer alternative to the React library.

## Current Status
The React version is marked as deprecated, suggesting developers should consider transitioning to the Web Components offering for new projects.
