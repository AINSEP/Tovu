Rebuilt as a Tovu `templated`-tier theme: layouts translated from Jekyll's
Liquid/HTML `_layouts` into `templates/home.liquid` and `templates/entry.liquid`
against Tovu's own template contract (`posts`, `post.title/slug/date/content`,
`render_block`), styles rewritten as `styles.css` + `tokens.json` using minima's
original color values. No original template or Sass source files are included.
