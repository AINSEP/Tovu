# Tovu Desktop 0.1.21

## New

- Site search, with Meilisearch as an optional provider plugin.
- Cookie Consent page, linked from Analytics.
- Import & Export panel with a Git backup card.
- Email provider settings; domain DNS plans and verification.
- The in-app assistant can use Claude in Chrome (on by default for the owner) and runs subagents.

## Fixed

- Post dates follow the site's time zone.
- Paged post lists (/page/2 and on) render and export.
- Removing a redirect moves it to the Trash.
- A deleted chat never comes back or receives messages.
- Agent plugins: the list no longer empties or cuts off rows.
- Long-running assistant sessions use less memory.
