# Tovu Desktop 0.1.31

## Improved

- Your personal MCP servers are on by default, so the assistant can use them without an extra switch.
- Shared Keys work across sites: a key you add once can be used by your other sites.
- Media cards have an Extra large size that is bigger than Large at every screen width.
- Calendly booking pages can be embedded on a site.
- Plugin code moved into the shared Jini runtime packages, so plugins behave the same everywhere Tovu runs.

## Fixed

- Deploy guidance for Railway and Render gives the right steps for each platform.
- A theme with more than 2,000 files still lists all its pages.
