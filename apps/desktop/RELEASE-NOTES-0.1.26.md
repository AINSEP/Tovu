# Tovu Desktop 0.1.26

## New

- Websites toolbar: icon buttons with tooltips, and Start/Stop/Restart as icons on each site card.
- Resources shows memory per site as a table.
- Export a site as a static website, or commit it to a GitHub folder.
- Share a site with its saved keys, encrypted with a password only you can reveal.
- A blank page template (no header or footer) for landing pages.
- The assistant: picked and dropped folders show as chips, "Starting assistant…" while it warms up, and "open X" goes straight there.
- Media: tighter cards, a size picker, and upload/import as icon buttons.

## Fixed

- A copied site gets its own identity and database, so it starts.
- A renamed site shows its new name right away.
- A slow first build no longer stops a starting site after two minutes.
- Codex chats and Word/PDF reading work in the packaged app.
- Post dates follow the site's time zone.
- The Posts editor picks up the assistant's edits.
- Sharing a site with saved keys works again.
- Many admin screens are now fully translated.
