# Tovu Desktop 0.1.20

## Fixed

- Creating a site on Windows no longer fails.
- Starting a site on a slow first boot no longer times out.
- The in-app assistant says why a chat could not continue, and a wait for you is never "no progress".
- The model picker lists each model once, by name.
- The Sites section stays hidden inside the desktop app.

## Improved

- Settings menu rebuilt: cleaner and keyboard-driven.
- SEO page: searchable entry picker, one Social preview section with an optional X card, and it shows the image a page really shares.
- Phones: the post editor toolbar fits one row; the rest is behind More.
- The expanded code viewer keeps a visible collapse button.
