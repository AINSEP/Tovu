# Glass background photo

`glass-bg.webp` is intentionally not supplied yet. Before registering the theme,
source a misty pale mountain lake photograph: open fog, desaturated blue-grey
mountains and water, no strong warm colours, text, logos, or distracting subjects.
Target approximately 2560px wide, WebP, no more than 400KB.

Use an open licence permitting redistribution with the application (for example
CC0, Unsplash, or Pexels). Do not redistribute either owner's reference image.
Record the original source URL, photographer/creator, exact licence name and URL,
download date, required attribution, and any edits here when supplying the asset.

Source: pending. Creator: pending. Licence: pending. No photo is licensed or bundled.

The URL layer precedes a blue-grey gradient, so a missing image still leaves the
gradient painted. Dark mode uses a deep blue-slate gradient. Reduced transparency and unsupported
backdrop filtering remove the photograph entirely and use the gradient alone.
