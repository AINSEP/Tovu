# H4 — `site-imports` (deps-split v4, hoisted closures → module functions)

Design tip: Tovu `2d82735a` (`origin/integ/merge-3-2026-11-18`), Jini `d37821a4`. One commit. Self-contained: COMMON rules are restated here.

## What moves
Root-level function declarations inside `composeSiteRouteDeps` (hoisted closures with `Record<string, never>` or empty placeholder signatures) become module functions with real `(required, optional = {})` inputs; each call passes the variables the body reads. No `await` is added or moved; the call stays where it is.

### `configureSiteImports` (tip 2916-2930, 12 code lines; called at tip 2914)
- **To**: `apps/website/src/server/runtime/composition/site-deps/site-imports.ts`, `export function configureSiteImports(required: ConfigureSiteImportsRequired, _optional = {}): void`; first body line `const { resolvedSiteBinding, workspaceId, observability, tracker, routeDeps, savedKeys } = required;`, then the tip body **verbatim** (getter fields read as `name()`), leading doc comment moved with it.
- **Call** (tip 2914, `configureSiteImports({}, {});`) becomes exactly:
```ts
  configureSiteImports({ resolvedSiteBinding, workspaceId, observability, tracker, routeDeps, savedKeys });
```
- **Inputs** (`ConfigureSiteImportsRequired`):

| field | how passed | type source (after the earlier sheets) |
|---|---|---|
| `resolvedSiteBinding` | value | B01 output → `ReturnType<typeof composeAgentPluginBootstrap>["resolvedSiteBinding"]` |
| `workspaceId` | value | `const workspaceId = await resolveWorkspaceIdOverride(kernel, overrides);` |
| `observability` | value | `const { observability, tracker, aiTraceSink } = providerPlugins;` |
| `tracker` | value | `const { observability, tracker, aiTraceSink } = providerPlugins;` |
| `routeDeps` | value | `const routeDeps: NewsletterRouteDeps & ByokToolSurfaceDeps = {` |
| `savedKeys` | value | `const savedKeys = composeSiteSavedKeys({ workspaceId, sealer: siteAssistantSecretSealer });` |

Type each required field mechanically: a B-sheet output → `ReturnType<typeof composeX>["name"]` as shown; `const x = f(…)` → `ReturnType<typeof f>`; `const x = await f(…)` → `Awaited<ReturnType<typeof f>>`; `const { x } = f(…)` → `ReturnType<typeof f>["x"]` (renamed `{ a: x }` → `["a"]`; with `await`, wrap in `Awaited<…>` first); `const x = await g(…)(…)` → `Awaited<ReturnType<ReturnType<typeof g>>>`; `new C(…)` → `C`; an annotated declaration → its annotation; `overrides` → `Partial<CreateSiteRouteDepsOverrides>` from `./overrides.js`; `dbPath` → `string`; `store` → `SiteStore`; `onStoreClose` → `(required: { registration: StoreCloseRegistration }, optional?: Record<string, never>) => void` with `StoreCloseRegistration` from `./open-store.js`; `kernel` → `SiteStore["content"]`; `workspaceId` → `string`. A getter field is `() => T` with T from the same rule. If typecheck rejects one field's type, replace that field's type with the type TypeScript names in the error and nothing else; any other typecheck error is STOP-TYPE.

A getter is required wherever the binding is declared after the call or is a root `let` reassigned after it; passing such a binding as a value is either a TypeScript error (TS2448/TS2454) or reads a stale cell — the characterization test fails on the latter.

## Characterization test (add `apps/website/src/server/runtime/composition/site-deps/__tests__/site-imports.characterization.unit.test.ts`)
```ts
import assert from "node:assert/strict";
import fs from "node:fs";
import test from "node:test";
import ts from "typescript";

// Pins: the calls keep their place in composeSiteRouteDeps, no root-level declaration of the moved
// functions remains, each is a module function with real inputs, and getter inputs are read lazily.
const DEPS = new URL("../../deps.ts", import.meta.url);
const parse = (url: URL): ts.SourceFile => ts.createSourceFile(url.pathname, fs.readFileSync(url, "utf8"), ts.ScriptTarget.Latest, true);
const firstLine = (node: ts.Node): string => node.getText().split("\n")[0].trim();
function bodyOf(file: ts.SourceFile, name: string): readonly ts.Statement[] {
  const found = file.statements.find((s): s is ts.FunctionDeclaration => ts.isFunctionDeclaration(s) && s.name?.text === name);
  assert.ok(found?.body, `${name} not found`);
  return found.body.statements;
}
function eagerReads(statements: readonly ts.Node[], getters: readonly string[]): string[] {
  const eager: string[] = [];
  const visit = (node: ts.Node, nested: boolean): void => {
    const parent = node.parent;
    if (ts.isIdentifier(node) && getters.includes(node.text) && !nested && !(ts.isPropertyAccessExpression(parent) && parent.name === node) && !ts.isBindingElement(parent) && !ts.isPropertyAssignment(parent)) eager.push(node.text);
    ts.forEachChild(node, (child) => visit(child, nested || ts.isFunctionLike(child)));
  };
  for (const statement of statements) visit(statement, false);
  return eager;
}
const FILES: Record<string, URL> = {"configureSiteImports":"../site-imports.ts"};

test("H4: the calls keep their place and the root declares none of the functions", () => {
  const body = bodyOf(parse(DEPS), "composeSiteRouteDeps");
  assert.deepEqual(body.filter((s) => ts.isFunctionDeclaration(s)).map((s) => (s as ts.FunctionDeclaration).name?.text).filter((n) => ["configureSiteImports"].includes(n ?? "")), []);
  { const at = body.findIndex((s) => firstLine(s).startsWith("configureSiteImports({")); assert.ok(at > 0, "configureSiteImports call missing"); assert.ok(firstLine(body[at - 1]).startsWith("function configureSiteSharing(_required: Record<string, never>, _options = {}): void {")); }
});

test("H4: each function is a module function whose first statement destructures its inputs", () => {
  for (const [name, url] of Object.entries(FILES)) {
    const first = bodyOf(parse(new URL(url, import.meta.url)), name)[0];
    assert.ok(first && ts.isVariableStatement(first) && first.getText().endsWith("= required;"), name);
  }
});

test("H4: getter inputs are only read lazily", () => {
  const getters: readonly string[] = [];
  for (const [name, url] of Object.entries(FILES)) assert.deepEqual(eagerReads(bodyOf(parse(new URL(url, import.meta.url)), name), getters), [], name);
});
```
