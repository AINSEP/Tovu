An acyclic graph can still block extraction when a package selects another package’s implementation.

I used Tovu `f7185f153`, Jini `4902a6a1a`, and the plan ref `18f1b17c0`. Counts are source occurrences across production `packages/**/src`, including the nested `cms-forms` package. I found one literal runtime dynamic load across packages and no literal sibling-relative load in the inspected matches. I reached the 200-lookup cap. No files changed and no tests, builds, installs, or type-checks ran.
