## What Looks Solid and Should Stay Unchanged

1. **Shared-Module Extensions (`features/entries/` and `navigation/resolver.ts`)**:
   - `features/entries/field-validation.ts`: The addition of the optional `owner` parameter defaulting to `"site"` is clean, additive, and 100% non-breaking for existing content types.
   - `features/entries/write-service.ts`: The optional `onWritten` callback inside `entryRepo.transaction()` properly establishes same-transaction execution under SQLite's `BEGIN IMMEDIATE`/`COMMIT` semantics.
   - `navigation/resolver.ts`: Exporting `resolveMenuDoc` cleanly opens menu document resolution without mutating or breaking existing location-based callers.

2. **Region-Binding Architecture (`region-area-service.ts` & `WidgetRegionBindingRepoPort`)**:
   - `widget_area` entries as the sole source of truth with `widget_region_bindings` as a derived, non-revision-generating projection perfectly fulfills ADR-047 Debate Fold-In Amendment 1 and INV-02/INV-03.
   - Reordering placements via whole-document OCC version checks operates reliably without per-row concurrency bugs.

3. **Batch-First Resolver Orchestration (`resolver-service.ts` & core resolvers)**:
   - `resolvePageWidgets` cleanly groups widget instances by type, executes at most one `WHERE id IN (...)` batch query per type, enforces cost clamps, and isolates resolver timeouts/exceptions behind failure placeholders (INV-05, REQ-23–28).
   - `contact-form` resolver (`resolvers/contact-form.ts`) strictly acts as a read adapter over `src/forms/` without duplicating submission or mail delivery pipelines (INV-08).

### 1. Fix `trashWidgetInstance` and `purgeWidgetInstance` `onWritten` Missing Callback (`src/widgets/write-service.ts`)

In `src/widgets/write-service.ts`, `trashWidgetInstance` and `purgeWidgetInstance` must pass `onWritten` to update/retract outgoing references in `entry_refs` upon status changes.

```typescript
// src/widgets/write-service.ts

export async function trashWidgetInstance(
  deps: WriteServiceDeps,
  actor: PrincipalActor,
  input: { workspaceId: UUID; id: UUID; baseVersion?: number }
): Promise<WidgetInstanceEntry> {
  await requireWidgetPermission(deps, actor, input.workspaceId, "widgets.delete");
  const existing = await getWidgetInstanceOrThrow(deps, input.workspaceId, input.id);
  const updated = await updateEntry(deps.entryRepo, {
    actor,
    workspaceId: input.workspaceId,
    entryId: input.id,
    expectedVersion: input.baseVersion,
    status: "trash",
    owner: WIDGET_FIELD_NAMESPACE,
    onWritten: async (entry) => {
      await extractAndStoreInstanceRefs(deps, entry);
    },
  });
  return mapEntryToWidgetInstance(updated);
}

export async function purgeWidgetInstance(
  deps: WriteServiceDeps,
  actor: PrincipalActor,
  input: { workspaceId: UUID; id: UUID; force?: boolean }
): Promise<WidgetInstanceEntry> {
  const perm = input.force ? "widgets.delete.force" : "widgets.delete";
  await requireWidgetPermission(deps, actor, input.workspaceId, perm);
  const existing = await getWidgetInstanceOrThrow(deps, input.workspaceId, input.id);

  if (!input.force) {
    const refs = await deps.entryRefsRepo.findReferencingSources({
      workspaceId: input.workspaceId,
      targetId: input.id,
    });
    if (refs.length > 0) {
      throw new WidgetReferencedError(
        `Cannot purge widget ${input.id}: referenced in ${refs.length} place(s)`,
        refs.map((r) => ({ sourceEntryId: r.sourceEntryId, fieldPath: r.fieldPath }))
      );
    }
  }

  const updated = await updateEntry(deps.entryRepo, {
    actor,
    workspaceId: input.workspaceId,
    entryId: input.id,
    status: "purged",
    owner: WIDGET_FIELD_NAMESPACE,
    onWritten: async (entry) => {
      await extractAndStoreInstanceRefs(deps, entry);
    },
  });
  return mapEntryToWidgetInstance(updated);
}
```

### 2. Implement `widgets.read` Accessors and Permission Gating (`src/widgets/write-service.ts`)

Export `getWidgetInstance` and `listWidgetInstances` with explicit permission checks to fulfill REQ-04, REQ-41, and INV-07.

```typescript
// src/widgets/write-service.ts (Additions)

export async function getWidgetInstance(
  deps: WriteServiceDeps,
  actor: PrincipalActor,
  input: { workspaceId: UUID; id: UUID }
): Promise<WidgetInstanceEntry | null> {
  await requireWidgetPermission(deps, actor, input.workspaceId, "widgets.read");
  const entry = await deps.entryRepo.findById(input.workspaceId, input.id);
  if (!entry || entry.type !== WIDGET_CONTENT_TYPE) {
    return null;
  }
  return mapEntryToWidgetInstance(entry);
}

export async function listWidgetInstances(
  deps: WriteServiceDeps,
  actor: PrincipalActor,
  input: { workspaceId: UUID }
): Promise<WidgetInstanceEntry[]> {
  await requireWidgetPermission(deps, actor, input.workspaceId, "widgets.read");
  const entries = await deps.entryRepo.listByWorkspace(input.workspaceId, WIDGET_CONTENT_TYPE);
  return entries.map(mapEntryToWidgetInstance);
}
```

### 4. Create `src/widgets/embed-service.ts` for Server-Side Embed Mutations (C-007, REQ-44, REQ-45)

Create the missing `embed-service.ts` module to satisfy REQ-44, REQ-45, AC-30, and AC-11.

```typescript
// src/widgets/embed-service.ts

import type { PrincipalActor, UUID } from "../core/ports";
import type { EntryRepoPort } from "../features/entries/write-service";
import { updateEntry } from "../features/entries/write-service";
import type { EntryRefsRepoPort } from "../core/entry-refs/ports";
import type { WidgetEmbedNode } from "./types";
import { requireWidgetPermission } from "./write-service";
import { validateWidgetEmbedMutation } from "./embed-validation";
import { extractAndStoreInstanceRefs } from "./write-service";
import { WidgetEmbedGuardrailError } from "./errors";

export interface EmbedServiceDeps {
  entryRepo: EntryRepoPort;
  entryRefsRepo: EntryRefsRepoPort;
  authorize?: (actor: PrincipalActor, workspaceId: UUID, permission: string) => Promise<boolean>;
}

export async function insertWidgetEmbed(
  deps: EmbedServiceDeps,
  actor: PrincipalActor,
  input: {
    workspaceId: UUID;
    hostEntryId: UUID;
    widgetEntryId: UUID;
    placementId: UUID;
    baseVersion?: number;
  }
): Promise<void> {
  await requireWidgetPermission(deps, actor, input.workspaceId, "widgets.update");

  const hostEntry = await deps.entryRepo.findById(input.workspaceId, input.hostEntryId);
  if (!hostEntry) {
    throw new Error(`Host entry ${input.hostEntryId} not found`);
  }

  const newEmbedNode: WidgetEmbedNode = {
    type: "widgetEmbed",
    placementId: input.placementId,
    widgetEntryId: input.widgetEntryId,
  };

  const currentBody = (hostEntry.bodyJson as { content?: unknown[] }) || { type: "doc", content: [] };
  const updatedBody = {
    ...currentBody,
    content: [...(currentBody.content || []), newEmbedNode],
  };

  const validation = validateWidgetEmbedMutation({
    hostEntryType: hostEntry.type,
    resultingBodyJson: updatedBody,
  });

  if (!validation.valid) {
    throw new WidgetEmbedGuardrailError(validation.reason);
  }

  await updateEntry(deps.entryRepo, {
    actor,
    workspaceId: input.workspaceId,
    entryId: input.hostEntryId,
    expectedVersion: input.baseVersion,
    bodyJson: updatedBody,
    onWritten: async (entry) => {
      await extractAndStoreInstanceRefs(deps, entry);
    },
  });
}
```

### Key Findings Summary

1. **`FINDING-WIDGETS-001` (Blocker — Domain 10: Unrecoverable Crash / Incomplete API)**
   - **Issue:** `src/widgets/embed-service.ts` is completely missing from the codebase (C-007: `insertWidgetEmbed`, `removeWidgetEmbed`, `reorderWidgetEmbeds` required by REQ-44, REQ-45, AC-30, AC-11, and ADR-047 Debate Fold-In Amendment 6).
   - **Impact:** Server-side document mutation for inline widget embeds is unavailable, leaving AI agent tools and backend services unable to insert or adjust inline embeds without a live browser editor session.

2. **`FINDING-WIDGETS-002` (Blocker — Domain 1: Authorization Bypass)**
   - **Issue:** No `getWidgetInstance` or `listWidgetInstances` accessors exist in `src/widgets/write-service.ts` or anywhere else in `src/widgets/`.
   - **Impact:** Zero domain-level enforcement of `widgets.read` permission exists. Callers and AI tools fetching widget instances must bypass permission checks or call lower-level entry APIs directly, violating INV-07.

3. **`FINDING-WIDGETS-003` (Blocker — Domain 3: Reference Integrity Violation)**
   - **Issue:** `trashWidgetInstance` and `purgeWidgetInstance` in `src/widgets/write-service.ts` invoke `updateEntry` without passing an `onWritten` callback.
   - **Impact:** When a widget instance (e.g. a `contact-form` referencing a `formDefinitionId`) is trashed or purged, `entry_refs` is not updated or retracted, leaving stale rows and corrupting safe-delete (`REQ-42`) checks on target entries.

4. **`FINDING-WIDGETS-004` (High — Domain 7: Registry Code-Injection Surface)**
   - **Issue:** `CORE_RESOLVERS` in `src/widgets/resolvers/index.ts` is typed as `Partial<Record<WidgetTypeKey, WidgetResolver>>` and indexed via `registration.resolverId as WidgetTypeKey`.
   - **Impact:** Tight-couples `resolverId` to `WidgetTypeKey`. Any registration where `resolverId !== typeKey` fails resolution silently and degrades to `resolver-error`.

5. **`FINDING-WIDGETS-005` (Medium — Domain 9: Test Coverage Gap)**
   - **Issue:** Automated tests in `src/widgets/__tests__/` and `src/core/entry-refs/__tests__/` only test `repo.memory.ts` adapters. `SqliteEntryRefsRepo` and `SqliteWidgetRegionBindingRepo` are never executed in automated tests.

### What Solid Parts Should Stay Unchanged
- **Shared-Module Extensions:** The `owner` parameter addition in `field-validation.ts`, `onWritten` callback plumbing in `write-service.ts`, and `resolveMenuDoc` export in `navigation/resolver.ts` are all safe, additive, and non-breaking for existing callers.
- **Region Binding Architecture:** The `widget_area` entry source of truth and `widget_region_bindings` derived projection cleanly satisfy INV-02/INV-03.
- **Batch-First Resolver Orchestration:** `resolvePageWidgets` cleanly handles batch querying, cost clamps, and failure isolation per INV-05/REQ-23–28.
