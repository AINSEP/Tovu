Tovu(1) General Commands Manual Tovu(1)

Name

tovu — a self-hosted content platform you operate by talking to it

Synopsis

$ tovu serve <site>

> move the September post to the top and regenerate the sitemap

Description

Runs a website and its admin from one site directory, on your machine.

Every capability the admin exposes — pages, themes, media, forms, members, plugins — is also a tool an agent can call. The screen and the tool reach the same operation, behind the same permission check.

So an agent can ask what the site can do, and then do it. That is the whole product.

Restrictions

Some operations were never handed over. The wording below is the catalog's own.

database_execute_migrate_forward NEVER agent-callableNot published to the model at all.
redirects_import NEVER agent-callableFive hundred routing rules is not an autonomous call.
deployment_execute_static_publish HUMAN-GATEDRaises a dialog and blocks until a person answers.
content_post_delete HUMAN-GATEDMoves to the trash. Never erases.
members_disable SOFT ONLYThe catalog ships no delete.

Themes

declarative
JSON blocks. A closed vocabulary the renderer will not step outside of.
templated
LiquidJS, against an AST-walked tag and filter allowlist.
handlebars
Helper allowlist. No partials, no decorators.
static
Plain HTML, CSS and JavaScript. This page is one.
code
Reserved. Nothing ships on it.

Every tier renders inside a worker_threads sandbox with a wall-clock timeout and heap caps, falling back to a built-in body on any failure.

Examples

Clone it and run it.

$ git clone https://github.com/leonaburime-ucla/Tovu.git
$ tovu serve my-site        # site and admin, one port
$ tovu export my-site       # static export
$ tovu introspect           # the command surface, as JSON

Or build the container instead.

$ docker build -t tovu:local .

Files

<site>/
The whole install. Point tovu serve at it.
Dockerfile
Multi-stage build at the repository root.

Bugs

Not published to npm. npm install tovu and npx tovu do not work; the package is private. Clone the repository or build the image.

The code theme tier is reserved and nothing ships on it.

Publishing to a static host needs a credential a person saved first. An agent cannot supply one, and cannot see one.

The repository, the documentation, the theme and plugin catalog.
