# S0 — pins on UNMOVED code (gate for every other S and U sheet). Tests only, Tovu only, no production edit.

```
id: S0-pins
feature: saved names and formats that lanes S and U carry across the boundary (plan-v6 §7 row G-id, re-derived from the code)
kind: characterization only (commit T0 for the whole lane); one Sonnet run, ~110k tokens
jini_target: -
prerequisites: -   (runs first; nothing else in lanes S/U may start before its cloud run is green AND its mutations are red)
```

Why this sheet exists: every later sheet moves a string that other processes, other versions or stored rows depend on.
A move that "passes typecheck" can still change one of them. These pins are written once, before any move, so each later
sheet inherits a failing test for its own named risk instead of writing a new one against already-moved code.

## Rules for this sheet
- Fixtures are literals in the test file, generated ONCE by running today's code in the cloud run and pasted; never
  regenerated by the test itself (a self-generating fixture cannot fail).
- Use the real SQLite kernel (`openMemorySqliteKernel` + Tovu migrations) with a thin recording wrapper that implements the
  kernel interface. No `vi.mock`.
- P5 hashes are security material by class only: the test names "stored token hash", never how to forge one.
- If a source line named above is not where the table says (the tree moved), re-locate it with
  `rg -n "lockKey\(" apps/website/src -g '!**/__tests__/**'` and report the corrected list; do not skip the pin.
