## Decisions And Constraints (owner-approved / established)

- **Three theme tiers** (ADR-020): Declarative (data-only, safe from anyone — the default, and column/signal already
  are the barebones starters; tovu-official is the flagship) · Templated (**LiquidJS**, sandboxed logic, no JS) ·
  Code (JS/components, trusted, signed-plugin framing).
- **ADR-020 amendment (post-debate) — carry these into the Tier-3 isolation ADR + the tiers spec slice:**
  1. **§6 CORRECTION:** same-origin theme JS can steal the logged-in admin/author session — "client-side" is NOT a
     safety boundary. Tier-3 client JS only from a **separate cookie-less/credential-isolated origin + strict CSP
     `connect-src 'none'`**; else themes ship NO code and motion (GSAP/Framer) comes from **signed plugin components**
     referenced by id.
  2. **Render IR is canonical** — JSON block-editor and Liquid both serialize to one render IR (lossless, additive
     migration). Keep JSON data-only (no control-flow DSL).
  3. **Prefer Astro / raw-JSX over Next.js** for the code tier (Next = framework capture of a self-hosted product).
- TipTap/ProseMirror renders server-side via one fixed schema-validated node→component mapping; themes never parse the
  AST. Runtime schema validation > compile-time template typing.
- "Fix upstream intent, not downstream drift." Theme edits need a server restart (no hot reload). Specs are hashed
  ground truth (re-hash via the Speckit validator with `--update-hash --phase spec`).
- Swarm peer wiring: Gemini voice = **agy** CLI (gemini CLI broken here); Codex = gpt-5.5 xhigh; Anthropic voice =
  Fable subagent; host Opus = Primary. Weight Codex+Fable over agy on splits.
