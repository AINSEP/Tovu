## ADDED LATER 2026-09-04

**Parked by the owner — do not spend time here:** Tailark theme licensing. Only the `basic` theme
matters. Attribution NOTICE.md files restored in `3857be19` stay; the terms question is closed.

**Open, not dispatched:**
- **`--border-strong` fails WCAG 1.4.11 site-wide.** `rgba(255,255,255,0.16)` dark = 1.74:1,
  `rgba(9,20,15,0.18)` light = 2.27:1, against a 3:1 floor for UI components. It is the theme
  toggle's focus ring on every page, not just the design sample that found it.
- **Privacy Policy overstates Google Fonts.** It names Google as a processor, but the LIVE site
  fetches zero fonts: `fontLink()` is called from exactly ONE place (`render.ts:2447`), inside the
  DECLARATIVE document shell. Static-tier themes supply their own `<head>` and never reach it.
  Verified: 0 googleapis refs on `/`, `/about`, `/docs`, `/catalog`. Correct the policy.
- **Geist never actually loads.** Same root cause. `theme.json` declares Geist/Geist Mono and the
  tokens reference them, but nothing fetches them, so the site renders in system fallback faces.
  The typography you think you are looking at is not the typography specified.
- **Self-hosting the fonts is MOOT** — nothing is fetched, so there is no IP transmission to remove.
- **`data-kui-stagger` is a PARENT ATTRIBUTE**, not the `stagger:` inline parameter the kUInetic
  catalog implies. `stagger:` inside `data-kui` is a split-text parameter. I passed the wrong form to
  the motion migration; verify its call sites against the real syntax.
- **`pages.edit_html` is unenforceable**, so an `editor`-role principal — not just an admin — can
  inject executable JavaScript into a public page (`update-html.ts:100-112`, which self-identifies as
  an open decision). Fine while the owner is the only user.
- **No site-wide custom-head setting exists.** The `page-head.ts` contributor registry is the right
  seam (already folded into every render) but has a closed 5-kind union and one hardcoded registrant.

**Owner rulings recorded:** copy must be ruthlessly terse (war on excessive text); Apache-2.0 with
`Copyright 2026 Tovu`; motion.js retired from `basic` only, both trees; kUInetic is the sole
animation library.
