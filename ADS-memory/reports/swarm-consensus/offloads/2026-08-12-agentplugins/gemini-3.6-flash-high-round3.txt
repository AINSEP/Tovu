### 1. Position Statement
My position is **Option 1: Centralized Immutable Plugin Store (`PLUGIN_ROOT`) + Isolated Per-Workspace Data Directory (`PLUGIN_DATA`) + Host Adapter with Explicit Operator Admission for MCP Servers**.

Third-party Agent Plugins downloaded from a marketplace land physical files on disk. To prevent security vulnerabilities and maintain structural integrity, Tovu must separate static, immutable plugin assets (`PLUGIN_ROOT`) from dynamic, workspace-bound state (`PLUGIN_DATA`). 

- **Skills → Passive Context Injection:** Markdown instructions in `skills/*/SKILL.md` are projected into the assistant composer as context assembly bindings (`insert-text`). They run zero subprocesses and require no execution trust model.
- **MCP Servers → Operator-Admitted Subprocesses:** Server definitions in `mcp.json` are ingested into an *unadmitted* preview-only state (`execute: unavailable`). They are executed via `mcp-federation` *only* after a site operator explicitly approves individual tool names in workspace settings.
- **Strict Path & Extraction Containment:** Package extraction enforces Zip-Slip prevention, symlink resolution boundary checks, and path canonicalization. `PLUGIN_ROOT` is marked read-only on disk (`0o555`), while `PLUGIN_DATA` is created per-workspace before any subprocess launch.

Host capability adapters synthesize labels, argument schemas, and execute bindings directly from standard spec manifests (`plugin.json`, `SKILL.md`, `mcp.json`).

1. **Agent Plugins Specification (v1.0.0)** — [https://agent-plugins.org/specification](https://agent-plugins.org/specification)
   - *Confirmed:* `PLUGIN_ROOT` is the absolute path to the plugin installation directory. `PLUGIN_DATA` is a client-managed persistent data directory dedicated to an installed plugin instance. Clients MUST expand `${PLUGIN_ROOT}` and `${PLUGIN_DATA}` in `args`, `env`, and `cwd`, and MUST enforce path containment preventing paths from escaping these boundaries via `../`.
2. **Snyk Zip Slip Vulnerability & Extraction Mitigations** — [https://github.com/snyk/zip-slip-vulnerability](https://github.com/snyk/zip-slip-vulnerability)
   - *Confirmed:* Archive extraction path traversal (Zip Slip) occurs when extracted filenames contain `../` sequences or absolute paths that write outside the destination directory. Mitigations require canonicalizing target paths using `realpath` / `path.resolve` and verifying the target path starts with the base extraction directory *before* writing any file or creating directories.

   - *Confirmed:* VS Code separates global immutable extension code (`~/.vscode/extensions`, analogue to `PLUGIN_ROOT`) from user/workspace persistent state and settings (`PLUGIN_DATA` analogue). Storing extension code globally prevents duplicate workspace downloads and avoids data pollution.

   - *Confirmed:* SQLite JSONB is an internal binary representation intended strictly for in-memory processing, not persistent storage across engine versions. Declaring a SQLite column type as `JSONB` falls through SQLite's affinity rules to `NUMERIC` affinity, silently coercing string values like `'123'` into numeric `123`.

### 2. `files/tovu/plugin-installer.ts`
*Secure archive extraction pipeline enforcing Zip-Slip protection, symlink isolation, and `PLUGIN_ROOT` vs `PLUGIN_DATA` separation.*

```typescript
import { chmod, mkdir, realpath, lstat, writeFile, rename, rm } from "node:fs/promises";
import path from "node:path";
import { createHash } from "node:hash";

export interface PluginInstallPaths {
  readonly pluginRoot: string; // Global immutable root
  readonly pluginData: string; // Per-workspace writable data directory
}

export interface RawArchiveEntry {
  readonly path: string;
  readonly content: Buffer;
  readonly isSymlink?: boolean;
  readonly symlinkTarget?: string;
}

export function sanitizePackagePath(baseDir: string, relativePath: string): string {
  if (relativePath.includes("\0") || path.isAbsolute(relativePath)) {
    throw new Error(`Unsafe absolute or null-byte path: '${relativePath}'`);
  }

  const normalized = path.normalize(relativePath.replace(/\\/g, "/"));
  const targetPath = path.resolve(baseDir, normalized);

  const relative = path.relative(baseDir, targetPath);
  const isOutside =
    relative === ".." ||
    relative.startsWith(`..${path.sep}`) ||
    path.isAbsolute(relative);

  if (isOutside) {
    throw new Error(`Zip-Slip directory traversal rejected: '${relativePath}'`);
  }

  return targetPath;
}

export async function extractAgentPluginArchive(input: {
  readonly pluginId: string;
  readonly version: string;
  readonly workspaceId: string;
  readonly entries: readonly RawArchiveEntry[];
  readonly baseStoreDir?: string;
  readonly baseWorkspaceDir?: string;
}): Promise<PluginInstallPaths> {
  const storeBase = input.baseStoreDir ?? process.env.TOVU_AGENT_PLUGINS_DIR ?? path.resolve("infra/agent-plugins/store");
  const wsBase = input.baseWorkspaceDir ?? path.resolve(`infra/agent-plugins/ws/${input.workspaceId}`);

  const targetPluginRoot = path.join(storeBase, input.pluginId, input.version);
  const targetPluginData = path.join(wsBase, input.pluginId, "data");

  const tempExtractDir = path.join(storeBase, ".tmp", `${input.pluginId}-${Date.now()}`);

  try {
    await mkdir(tempExtractDir, { recursive: true });

    for (const entry of input.entries) {
      const targetFilePath = sanitizePackagePath(tempExtractDir, entry.path);

      if (entry.isSymlink && entry.symlinkTarget) {
        // Reject symlinks pointing outside extraction root
        const resolvedSymlinkTarget = path.resolve(path.dirname(targetFilePath), entry.symlinkTarget);
        const relativeSymlink = path.relative(tempExtractDir, resolvedSymlinkTarget);
        if (relativeSymlink.startsWith("..") || path.isAbsolute(relativeSymlink)) {
          throw new Error(`Symlink escape rejected: '${entry.path}' -> '${entry.symlinkTarget}'`);
        }
        await mkdir(path.dirname(targetFilePath), { recursive: true });
        await writeFile(targetFilePath, entry.symlinkTarget, "utf8");
      } else {
        await mkdir(path.dirname(targetFilePath), { recursive: true });
        await writeFile(targetFilePath, entry.content);
      }
    }

    // Verify extraction root realpath confinement
    const realTemp = await realpath(tempExtractDir);
    for (const entry of input.entries) {
      const entryPath = sanitizePackagePath(realTemp, entry.path);
      const entryStat = await lstat(entryPath);
      if (entryStat.isSymbolicLink()) {
        const realEntry = await realpath(entryPath);
        const rel = path.relative(realTemp, realEntry);
        if (rel.startsWith("..") || path.isAbsolute(rel)) {
          throw new Error(`Post-extract symlink escape detected: '${entry.path}'`);
        }
      }
    }

    // Atomic move into immutable plugin root store
    await mkdir(path.dirname(targetPluginRoot), { recursive: true });
    await rm(targetPluginRoot, { recursive: true, force: true });
    await rename(tempExtractDir, targetPluginRoot);

    // Create per-workspace writable PLUGIN_DATA directory
    await mkdir(targetPluginData, { recursive: true });

    return {
      pluginRoot: targetPluginRoot,
      pluginData: targetPluginData,
    };
  } catch (err) {
    await rm(tempExtractDir, { recursive: true, force: true }).catch(() => {});
    throw err;
  }
}
```

```typescript
import path from "node:path";
import { readFile, realpath, stat } from "node:fs/promises";
import type {
  CapabilityDescriptor,
  CapabilityRegistration,
  CapabilitySource,
  JsonSchemaObject,
  PreviewBundle,
  PreviewDocument,
} from "./capability-contract.js";

const EMPTY_SCHEMA: JsonSchemaObject = {
  type: "object",
  additionalProperties: false,
  required: [],
  properties: {},
};

export interface PluginManifest {
  readonly $schema?: string;
  readonly name: string;
  readonly version: string;
  readonly description?: string;
}

export interface McpManifest {
  readonly $schema?: string;
  readonly mcpServers?: Record<string, { readonly command?: string; readonly args?: readonly string[]; readonly tools?: readonly string[] }>;
}

export interface DiskAgentPluginPackage {
  readonly pluginRoot: string;
  readonly digest: string;
  readonly manifest: PluginManifest;
  readonly mcpManifest?: McpManifest;
  readonly fileList: readonly string[];
}

function parseSchemaVersion(schemaUri?: string): string | null {
  if (!schemaUri) return null;
  const match = schemaUri.match(/\/schemas\/(\d+\.\d+\.\d+)\/(?:plugin|mcp)\.schema\.json$/);
  return match ? match[1] : null;
}

export function makeSafeFilePreviewProvider(
  packageRoot: string,
  allowedPaths: readonly string[],
  title: string
): () => Promise<PreviewBundle> {
  return async () => {
    const realRoot = await realpath(packageRoot);
    const documents: PreviewDocument[] = [];

    for (const rawPath of allowedPaths) {
      const normalized = path.normalize(rawPath.replace(/\\/g, "/"));
      if (normalized.includes("..") || path.isAbsolute(normalized)) {
        throw new Error(`Traversal rejected in preview lookup: '${rawPath}'`);
      }

      const candidate = path.resolve(realRoot, normalized);
      const rel = path.relative(realRoot, candidate);
      if (rel.startsWith("..") || path.isAbsolute(rel)) {
        throw new Error(`Preview path escaped package root: '${rawPath}'`);
      }

      const realCandidate = await realpath(candidate);
      const realRel = path.relative(realRoot, realCandidate);
      if (realRel.startsWith("..") || path.isAbsolute(realRel)) {
        throw new Error(`Preview symlink escaped package root: '${rawPath}'`);
      }

      const metadata = await stat(realCandidate);
      if (!metadata.isFile()) continue;

      const content = await readFile(realCandidate, "utf8");
      const mediaType = normalized.endsWith(".md")
        ? "text/markdown"
        : normalized.endsWith(".json")
        ? "application/json"
        : "text/plain";

      documents.push({ path: normalized, mediaType, content });
    }

    return { title, documents };
  };
}

export function agentPluginCapabilityAdapter(
  pkg: DiskAgentPluginPackage,
  admittedToolIds: ReadonlySet<string>
): CapabilitySource {
  return {
    sourceId: `agent-plugin:${pkg.manifest.name}@${pkg.digest}`,

    async load(): Promise<readonly CapabilityRegistration[]> {
      const registrations: CapabilityRegistration[] = [];
      const baseProvenance = {
        sourceKind: "agent-plugin",
        sourceId: pkg.manifest.name,
        sourceVersion: pkg.manifest.version,
        contentDigest: pkg.digest,
      };

      // 1. Process Skills (skills/<name>/SKILL.md)
      const skillFiles = pkg.fileList.filter((f) => /^skills\/[^/]+\/SKILL\.md$/.test(f)).sort();

      for (const skillPath of skillFiles) {
        const skillName = skillPath.split("/")[1]!;
        const skillDir = path.dirname(skillPath);
        const relatedFiles = pkg.fileList.filter(
          (f) => f === skillPath || f.startsWith(`${skillDir}/references/`)
        );

        const capabilityId = `agent-plugin:${pkg.manifest.name}:skill:${skillName}`;
        const previewBinding = `preview:${capabilityId}:${pkg.digest}`;

        const previewLoader = makeSafeFilePreviewProvider(
          pkg.pluginRoot,
          relatedFiles,
          `Skill: ${skillName}`
        );

        registrations.push({
          descriptor: {
            contractVersion: 1,
            id: capabilityId,
            revision: pkg.digest,
            kind: "skill",
            label: skillName,
            description: `Context Skill '${skillName}' from ${pkg.manifest.name}`,
            keywords: ["skill", skillName, pkg.manifest.name],
            group: { id: "skills", label: "Skills" },
            command: {
              canonical: `agent-plugin:${pkg.manifest.name}:skill:${skillName}`,
              aliases: [skillName],
            },
            args: { schema: EMPTY_SCHEMA, presentation: [] },
            preview: { bindingId: previewBinding, title: `Skill: ${skillName}` },
            execute: { kind: "insert-text", text: `[Skill: ${skillName}]` },
            requiresConfirmation: false,
            availability: { state: "ready" },
            provenance: baseProvenance,
            trust: {
              decision: "admitted-context-only",
              assignedBy: { kind: "host", id: "tovu-agent-plugin-adapter" },
              basis: ["instruction injection only", "no subprocess execution"],
            },
          },
          preview: { bindingId: previewBinding, load: previewLoader },
        });
      }

      // 2. Process MCP Servers (mcp.json)
      if (pkg.mcpManifest) {
        const pluginVer = parseSchemaVersion(pkg.manifest.$schema);
        const mcpVer = parseSchemaVersion(pkg.mcpManifest.$schema);
        const schemaMismatch = pluginVer !== null && mcpVer !== null && pluginVer !== mcpVer;

        const servers = pkg.mcpManifest.mcpServers ?? {};
        for (const [serverName, serverSpec] of Object.entries(servers)) {
          const declaredTools = serverSpec.tools ?? [];

          for (const toolName of declaredTools) {
            const qualifiedToolId = `mcp__${pkg.manifest.name}_${serverName}__${toolName}`;
            const isAdmitted = admittedToolIds.has(qualifiedToolId);

            const capabilityId = `agent-plugin:${pkg.manifest.name}:mcp:${serverName}:${toolName}`;
            const previewBinding = `preview:${capabilityId}:${pkg.digest}`;

            let availability: CapabilityDescriptor["availability"];
            let executeBinding: CapabilityDescriptor["execute"];

            if (schemaMismatch) {
              availability = {
                state: "blocked",
                message: `MCP disabled: plugin schema (${pluginVer}) and mcp schema (${mcpVer}) mismatch.`,
              };
              executeBinding = { kind: "unavailable", reason: availability.message };
            } else if (!isAdmitted) {
              availability = {
                state: "preview-only",
                message: `Pending Operator Approval: Tool '${toolName}' is unadmitted.`,
              };
              executeBinding = { kind: "unavailable", reason: availability.message };
            } else {
              availability = { state: "ready" };
              executeBinding = { kind: "tool-call", toolId: qualifiedToolId };
            }

            registrations.push({
              descriptor: {
                contractVersion: 1,
                id: capabilityId,
                revision: pkg.digest,
                kind: "mcp-tool",
                label: `${serverName}:${toolName}`,
                description: `MCP tool '${toolName}' from ${serverName}`,
                keywords: ["mcp", serverName, toolName, pkg.manifest.name],
                group: { id: "mcp", label: "MCP Tools" },
                command: {
                  canonical: `agent-plugin:${pkg.manifest.name}:mcp:${serverName}:${toolName}`,
                  aliases: [toolName],
                },
                args: { schema: EMPTY_SCHEMA, presentation: [] },
                preview: { bindingId: previewBinding, title: `MCP Tool: ${toolName}` },
                execute: executeBinding,
                requiresConfirmation: !isAdmitted,
                availability,
                provenance: baseProvenance,
                trust: {
                  decision: isAdmitted ? "admitted-operator-allowlist" : "unadmitted",
                  assignedBy: { kind: "host", id: "tovu-agent-plugin-adapter" },
                  basis: isAdmitted
                    ? ["operator explicitly admitted tool ID in workspace settings"]
                    : ["plugin-authored mcp.json cannot self-admit subprocess execution"],
                },
              },
              preview: {
                bindingId: previewBinding,
                load: makeSafeFilePreviewProvider(
                  pkg.pluginRoot,
                  ["mcp.json"],
                  `MCP Manifest: ${serverName}`
                ),
              },
            });
          }
        }
      }

      return registrations;
    },
  };
}
```

## Critique Of Another Participant's Round 2 Code

### 1. Critique of `sonnet5-round2` — Fatal Bug in Schema Mismatch Check
In `sonnet5-round2` lines 1280–1281 (`agent-plugin-adapter.ts`), `sonnet5-round2` wrote:
```typescript
const schemaMismatch =
  pkg.mcpJsonSchema !== undefined &&
  pkg.pluginJsonSchema !== undefined &&
  pkg.mcpJsonSchema !== pkg.pluginJsonSchema;
```
**Why this breaks against real contracts:**
In the Agent Plugins specification (v1.0.0), `plugin.json` specifies its schema URI as `https://agent-plugins.org/schemas/1.0.0/plugin.schema.json`, whereas `mcp.json` specifies its schema URI as `https://agent-plugins.org/schemas/1.0.0/mcp.schema.json`. 

`sonnet5-round2` performs a direct string inequality check (`pkg.mcpJsonSchema !== pkg.pluginJsonSchema`) directly on the `$schema` strings. Because `".../plugin.schema.json"` is never string-identical to `".../mcp.schema.json"`, this check evaluates to `true` (**schema mismatch**) for **100% of fully compliant standard Agent Plugins**. Every valid spec-compliant plugin with both manifests is falsely classified as corrupted and disabled. Schema version checks must parse out the version subpath (e.g. `1.0.0`) via regex rather than comparing raw manifest `$schema` URLs.

### 3. Critique of `codex-round2` — Symlink Escape Timing in Preview Lookup
In `codex-round2` lines 578–587 (`capability-file-preview.ts`), `codex-round2` wrote:
```typescript
const safeRelative = normalizePackagePath(relativePath);
const realRoot = await realpath(packageRoot);
const lexicalCandidate = path.resolve(realRoot, safeRelative);

if (!isContained(realRoot, lexicalCandidate)) {
  throw new Error(`package traversal rejected: '${relativePath}'`);
}

const realCandidate = await realpath(lexicalCandidate);
if (!isContained(realRoot, realCandidate)) {
  throw new Error(`package symlink escape rejected: '${relativePath}'`);
}
```
**Why this construct is unsafe during archive extraction:**
If `safeRelative` names a symlink entry in an extracted package pointing outside `realRoot` (e.g. `skills/link -> /etc/passwd`), performing `path.resolve(realRoot, "skills/link")` produces `/path/to/package/skills/link`. Lexically, this candidate path lies inside `realRoot`, so `isContained(realRoot, lexicalCandidate)` passes. 

If the file is read before `realpath(lexicalCandidate)` is verified (or if an archive extractor extracts files in stream order without checking `lstat` before opening target write streams), an attacker can create a directory symlink in entry 1 and write target files through that symlink in entry 2 before `realCandidate` validation runs. Extractor routines must enforce `lstat` checks on every path component during stream processing.
