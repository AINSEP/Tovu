## Position And Movement

### Position
Deployment in Tovu is defined as: **promoting an immutable, workspace-scoped release to a named environment through a configured target, executing side effects via direct HTTP adapters using Tovu's guarded `HttpClientPort.send()`, and tracking progress via durable workspace-scoped run records.**

The owner's hypothesis — *"just MCP, access tokens and base URLs"* — is definitively rejected based on codebase facts:

Declaring a column as `JSONB` falls through to `NUMERIC` affinity, causing automatic coercion of numeric strings (e.g. `'123'` -> `123`). Binary SQLite JSONB should use `BLOB`, while text JSON should use `TEXT`.

### Option 1 (Leading / Recommended): Direct Provider HTTP Adapters with GitHub App Installation Tokens
- **Architecture**: Domain model (`Release`, `Environment`, `DeploymentTarget`, `DeploymentRun`, `DeploymentRunEvent`) backed by SQLite tables. `GitHubDeploymentAdapter` implements `DeploymentRuntimePort` over `HttpClientPort.send()`, minting 1-hour installation tokens from an RS256 App JWT. - **Genuine Sacrifice**: Operator friction registering a GitHub App (generating a private key and walking an installation flow) compared to pasting a PAT, plus maintaining provider-specific HTTP adapters in Tovu core.

### 2. Runtime Port & GitHub App Adapter over `HttpClientPort.send`

```typescript
// deployment/adapter.github.ts
import { createSign } from "node:crypto";
import type { UUID } from "@jini-ai/cms/core";
import type { EgressPolicy, HttpClientPort, HttpRequest, HttpResponse } from "../integrations-ports";
import type { DeploymentTarget, Release } from "./types";

export interface DeploymentRuntimePort {
  submit(input: {
    workspaceId: UUID;
    runId: UUID;
    release: Release;
    target: DeploymentTarget;
    appPrivateKeyPem: string;
  }): Promise<{ providerOperationId: string; providerState: string }>;

  inspect(input: {
    workspaceId: UUID;
    target: DeploymentTarget;
    providerOperationId: string;
    appPrivateKeyPem: string;
  }): Promise<{ state: "submitted" | "running" | "succeeded" | "failed"; providerState: string }>;
}

const GITHUB_API_ORIGIN = "https://api.github.com";

export class GitHubDeploymentAdapter implements DeploymentRuntimePort {
  constructor(
    private readonly httpClient: HttpClientPort,
    private readonly egressPolicy: EgressPolicy,
  ) {}

  private verifyOrigin(urlStr: string): void {
    const parsed = new URL(urlStr);
    if (parsed.origin !== GITHUB_API_ORIGIN) {
      throw new Error(`Security Violation: Adapter restricted to origin ${GITHUB_API_ORIGIN}, got ${parsed.origin}`);
    }
  }

  private async mintInstallationToken(appId: string, installationId: string, privateKeyPem: string): Promise<string> {
    const now = Math.floor(Date.now() / 1000);
    const header = Buffer.from(JSON.stringify({ alg: "RS256", typ: "JWT" })).toString("base64url");
    const payload = Buffer.from(JSON.stringify({ iat: now - 60, exp: now + 540, iss: appId })).toString("base64url");
    const signer = createSign("RSA-SHA256");
    signer.update(`${header}.${payload}`);
    const signature = signer.sign(privateKeyPem, "base64url");
    const jwt = `${header}.${payload}.${signature}`;

    const url = `${GITHUB_API_ORIGIN}/app/installations/${encodeURIComponent(installationId)}/access_tokens`;
    this.verifyOrigin(url);

    const response = await this.httpClient.send({
      method: "POST",
      url,
      headers: {
        Authorization: `Bearer ${jwt}`,
        Accept: "application/vnd.github+json",
        "User-Agent": "Tovu-Deployment-Engine",
        "X-GitHub-Api-Version": "2022-11-28",
      },
      egressPolicy: this.egressPolicy,
    });

    if (response.status !== 201) {
      throw new Error(`GitHub token exchange failed (${response.status}): ${response.body}`);
    }

    const data = JSON.parse(response.body) as { token: string };
    return data.token;
  }

  async submit(input: {
    workspaceId: UUID;
    runId: UUID;
    release: Release;
    target: DeploymentTarget;
    appPrivateKeyPem: string;
  }) {
    const token = await this.mintInstallationToken(
      input.target.config.appId,
      input.target.config.installationId,
      input.appPrivateKeyPem,
    );

    const url = `${GITHUB_API_ORIGIN}/repos/${encodeURIComponent(input.target.config.owner)}/${encodeURIComponent(input.target.config.repository)}/deployments`;
    this.verifyOrigin(url);

    const req: HttpRequest = {
      method: "POST",
      url,
      headers: {
        Authorization: `Bearer ${token}`,
        Accept: "application/vnd.github+json",
        "Content-Type": "application/json",
        "User-Agent": "Tovu-Deployment-Engine",
        "X-GitHub-Api-Version": "2022-11-28",
      },
      body: JSON.stringify({
        ref: input.release.artifact.digest,
        environment: input.target.name,
        task: input.target.config.task || "deploy",
        auto_merge: false,
        required_contexts: [],
        payload: { tovu_run_id: input.runId, workspace_id: input.workspaceId },
      }),
      egressPolicy: this.egressPolicy,
    };

    const res: HttpResponse = await this.httpClient.send(req);
    if (res.status !== 201) {
      throw new Error(`GitHub deployment creation failed (${res.status}): ${res.body}`);
    }

    const body = JSON.parse(res.body) as { id: number };
    return { providerOperationId: String(body.id), providerState: "queued" };
  }

  async inspect(input: {
    workspaceId: UUID;
    target: DeploymentTarget;
    providerOperationId: string;
    appPrivateKeyPem: string;
  }) {
    const token = await this.mintInstallationToken(
      input.target.config.appId,
      input.target.config.installationId,
      input.appPrivateKeyPem,
    );

    const url = `${GITHUB_API_ORIGIN}/repos/${encodeURIComponent(input.target.config.owner)}/${encodeURIComponent(input.target.config.repository)}/deployments/${encodeURIComponent(input.providerOperationId)}/statuses?per_page=1`;
    this.verifyOrigin(url);

    const res = await this.httpClient.send({
      method: "GET",
      url,
      headers: {
        Authorization: `Bearer ${token}`,
        Accept: "application/vnd.github+json",
        "User-Agent": "Tovu-Deployment-Engine",
        "X-GitHub-Api-Version": "2022-11-28",
      },
      egressPolicy: this.egressPolicy,
    });

    if (res.status !== 200) {
      throw new Error(`GitHub status inspection failed (${res.status}): ${res.body}`);
    }

    const statuses = JSON.parse(res.body) as Array<{ state: string }>;
    const latest = statuses[0]?.state || "queued";
    return mapGitHubState(latest);
  }
}

function mapGitHubState(state: string): { state: "submitted" | "running" | "succeeded" | "failed"; providerState: string } {
  switch (state) {
    case "success":
      return { state: "succeeded", providerState: state };
    case "failure":
    case "error":
      return { state: "failed", providerState: state };
    case "in_progress":
    case "queued":
    default:
      return { state: "running", providerState: state };
  }
}
```

### 3. Webhook Callback Route (`(providerId, providerRunRef) -> workspace` resolution)

```typescript
// deployment/webhook.ts
import { createHmac, timingSafeEqual } from "node:crypto";
import type { Express, Request, Response } from "express";
import type { DeploymentRun } from "./types";

export interface WebhookRouteDeps {
  readonly getWebhookSecret: () => Promise<string>;
  readonly findRunByProviderRef: (providerOperationId: string) => Promise<DeploymentRun | null>;
  readonly updateRunStatus: (runId: string, state: string, version: number) => Promise<void>;
}

export function registerGitHubWebhookRoute(app: Express, deps: WebhookRouteDeps): void {
  app.post("/api/webhooks/github/deployments", async (req: Request, res: Response) => {
    const rawBody = req.body as Buffer;
    const signature = req.header("x-hub-signature-256") || "";

    const secret = await deps.getWebhookSecret();
    const hmac = createHmac("sha256", secret).update(rawBody).digest("hex");
    const expectedSig = `sha256=${hmac}`;

    if (!signature || !timingSafeEqual(Buffer.from(signature), Buffer.from(expectedSig))) {
      res.status(401).json({ error: "Invalid signature" });
      return;
    }

    if (req.header("x-github-event") !== "deployment_status") {
      res.status(202).json({ ignored: true });
      return;
    }

    const payload = JSON.parse(rawBody.toString("utf-8"));
    const deploymentId = String(payload.deployment?.id || "");

    // CRITICAL SECURITY INVARIANT: Workspace is resolved ONLY via DB lookup from deploymentId
    const run = await deps.findRunByProviderRef(deploymentId);
    if (!run) {
      res.status(202).json({ ignored: true, reason: "No matching run found for deployment ref" });
      return;
    }

    const newState = payload.deployment_status?.state === "success" ? "succeeded" : "failed";
    await deps.updateRunStatus(run.id, newState, run.version);

    res.status(200).json({ ok: true, runId: run.id, workspaceId: run.workspaceId });
  });
}
```

#### Code Defects & Failures Against Real Contracts
1. **Uncompiled `EgressPolicy` Fields**: As established in the preamble, Tovu's `EgressPolicy` contract contains `allowedSchemes`, `denyPrivateAddresses`, `devHostAllowlist`, `maxRedirects`, `connectTimeoutMs`, `maxResponseBytes`, `maxDecompressedBytes`, and `rateLimit`. It has **no `allowedHosts` or `followRedirects` properties**. Passing these fields produces TypeScript compiler errors (`TS2353: Object literal may only specify known properties`).
2. **Wrong Method Signature**: `sonnet5-round2` invoked `deps.http.request({...})`. Tovu's actual `HttpClientPort` method is `send(request: HttpRequest)`, not `.request(...)`.
3. **False Security Property**: Because `EgressPolicy` cannot express host restriction, `sonnet5-round2`'s reliance on `allowedHosts` provides zero origin pinning. If a target URL is configured maliciously, `HttpClientPort.send()` will execute outbound requests to non-GitHub hosts. Host origin verification MUST be explicitly checked inside the adapter logic prior to calling `send()`.
