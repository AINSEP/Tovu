### AGENTS.md (repo root) — "Cloud Dispatch — Standing Rules", rule 1
CLAIMED:  "This repo declares ~10 dependencies as `file:../Jini/packages/*`, so the Jini checkout must

ACTUAL:   False as of two days before this audit. Commit `daa74a65` (2026-08-31, "build(deps): consume
@jini-ai packages from npm instead of file: links") switched every `@jini-ai/*` dependency in
`package.json`, `apps/admin/package.json`, and `apps/site-chat/package.json` to ordinary npm-registry
semver ranges (`^0.3.x`). `package-lock.json` confirms these resolve to

a historical artifact at `development/.jini-local-backup/package.json` — not the active manifest.

real run") — an unattended cloud-dispatched agent trusting this rule would waste real setup time
cloning and building a sibling repo that is no longer used.
EVIDENCE: `grep -n "jini-ai" package.json apps/admin/package.json apps/site-chat/package.json` (all
`^0.3.x`, zero `file:` hits); `grep -A2 "node_modules/@jini-ai/core" package-lock.json` (resolved from
`registry.npmjs.org`); `git log --follow -p -- package.json` isolating the exact commit `daa74a65`
that made the switch; `grep -rn "file:../Jini" --include=package.json` (only hit: the backup file).
ACTION:   fixed — rewrote rule 1 to state the real (npm-based) setup, cited the commit, kept the
"green baseline before changes" advice which is still sound.
