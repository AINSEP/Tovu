### Exception candidates

- EXCEPTION `main/index.ts:230–1347` (reported ranges only) — native Electron composition and top-level listeners. A bare Node import would execute boot; remaining native behavior needs a launch-enabled harness or an extracted seam, not tests of copied source.
- EXCEPTION `renderer/main.tsx:1–40` — renderer entry binds the real document, CSS and providers and mounts immediately. Its UI and telemetry behavior are tested below that entry; direct composition belongs in the bundled Electron test.
- EXCEPTION `renderer/App.hooks.ts:1–30` — comment block in a re-export barrel; the exact export identities already have tests in `renderer/App.hooks.test.ts`.
- EXCEPTION `desktop-i18n.ts:174,176–179` — the fallback rows guard missing translations of otherwise-supported keys. Current public inputs cannot select such a missing row without changing shipped data; dictionary invariants pin the healthy case.
- EXCEPTION `product-telemetry-ipc.ts:20–22` (missing-event/non-array alternatives only) — both static catalog entries exist with list rules. Renderer payload tests exercise the actual accepted IDs and refused IDs without replacing the catalog.
- EXCEPTION `external-site-stop.ts:202` — a built-in Map with at least 64 entries always has a first key.
- EXCEPTION `desktop-resources.ts:61,135,170` — readings are built from the same rows, and the private-memory callback is only exposed when the sampler exists.
