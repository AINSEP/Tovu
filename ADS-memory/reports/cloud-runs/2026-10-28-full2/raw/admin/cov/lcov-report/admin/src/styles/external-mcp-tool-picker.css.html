/**
 * @file External-MCP write-tool picker + the per-server tools modal (`ExternalMcpToolsModal.tsx`)
 * that replaced the old Connection/Tools tab layout — Phase 4 of `ADS-memory/reports/pipeline/
 * external-mcp-write-tools/implementation-outline.md`. Classes match `ExternalMcpSettingsPanel.tsx`
 * (`.external-mcp-source`), `ExternalMcpToolsModal.tsx` (`.external-mcp-tools-modal*`), and
 * `ExternalMcpToolPicker.tsx` (`.external-mcp-tool-*`) verbatim.
 *
 * ## Every control here declares `color` explicitly
 *
 * This app's global reset (`styles.css:279`) sets `button { background: var(--primary); color:
 * var(--primary-ink); }` on every bare `<button>`. A rule here that set `background`/`border` but
 * left `color` alone would WIN the two it named and silently LOSE color back to that reset — the
 * near-white-on-near-white failure that shipped on the sibling settings card's Edit/Save/Cancel
 * pills (fixed in Jini `b82cbe95`; a prior instance is `settings-dialog.css:851-865`). So every rule
 * below that touches a `<button>` or a checkbox `<label>` names `color`, even where the value would
 * otherwise be inherited correctly — see `styles/__tests__/external-mcp-tool-picker-css.unit.test.ts`
 * for the regression pin. `.btn-secondary` (`styles.css:1084`) already gets this right on its own,
 * so the header actions reuse it rather than re-deriving the same rule for Refresh/Cancel.
 *
 * ## The scrolling list
 *
 * The live higgsfield connection advertises 157 tools. `.external-mcp-tool-list` is the dialog's one
 * scrolling container, bounded by the dialog's fixed-height flex column (2026-10-13; was its own
 * `max-height: 22rem` inside a second scrolling modal body), so a wide-open server cannot grow the
 * dialog to match it, and every
 * row's tool NAME wraps (`overflow-wrap: anywhere`) rather than clipping or forcing the row wider.
 * jsdom cannot verify either property (no real layout engine), so both are verified live in the
 * browser, not by a component test.
 *
 * A row's DESCRIPTION no longer follows that "always fully visible" rule (2026-09-13, owner: the
 * wrapped third-party text ran long enough per row to dominate a 101-row list) — it clamps to 3
 * lines (one line since 2026-10-13) via `SeeMore` (`ExternalMcpToolPicker.tsx`), with a "See more" toggle rather than a second
 * scroll-within-a-scroll. Text still is never SLICED — `SeeMore`'s own header explains why the full
 * string stays in the DOM, just visually clamped, so in-page search and screen readers still see it.
 */
 
.external-mcp-source + .external-mcp-source {
  margin-top: 1rem;
}
