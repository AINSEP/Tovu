**MEDIUM — CONFIRMED.** `apps/website/src/features/custom-credentials/credentialed-request.ts:305-313` (`redactResponseHeaders`), commit 922f2ef6. Response-body redaction got a documented length floor (`MIN_SAFE_BODY_REDACTION_TOKEN_LENGTH = 8`, `resolveRedactedResponseBody:337`) specifically because short tokens over-match ordinary content — but `redactResponseHeaders` applies no floor at all: it drops any header whose value `.includes()` a secret, regardless of length.
