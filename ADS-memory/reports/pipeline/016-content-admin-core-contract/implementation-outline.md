- Open risks or ambiguities: none beyond the two open questions already carried from SPEC-016 itself (OQ-01 watermark contention benchmark, owed at SPEC-017 sign-off; OQ-03 Postgres `CUTOVER` mechanism, owed before the Postgres adapter's implementation begins).
