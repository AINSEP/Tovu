They reuse the existing credential resolver, confirmation exchanges, authorization and deployment ledger. Domain attachment can therefore run after a new deployment **or against an existing deployment without republishing**.

A domain preview returns both hostnames, current records/bindings/routes, exact additions/removals/updates, expected interruption, and recovery steps. Bind its opaque plan ID to workspace, actor, target resource, credential ID/revision, inspected state and expiry. Execution requires the human confirmation, rechecks state before mutations, and refuses stale plans. Do not accept a model-supplied `confirmed:true` as approval.
