## Delivered behavior

- Shared page shaping: parse HTML before text caps, remove executable/inert markup/comments,
  decode entities, collapse whitespace, and return literal case-insensitive search snippets with
  UTF-16 offsets, full available-source matchCount, 160-character context, max 20 matches and
  byte-budget truncation. No-option local output preserves existing raw-byte/decode behavior.
- fetch_published_page accepts find/textOnly and retains its existing path/permission rules.
- fetch_live_url reads this workspace's current connected/keyed peer origins, all distinct saved
  static-publish URLs, and trusted canonical configured origin (workspace-setting, including the
  operator's TOVU_PUBLIC_URL). Development/request Host origins are excluded. Selection refuses
  zero/ambiguous/unknown origins with actionable errors. GETs use the same guarded/pinned client
  as media import, no credentials/body, one 15-second deadline, at most three same-origin redirects,
  and bounded decoded streams. Cross-origin/fourth redirects are response evidence. Cookie values
  are removed; live results carry untrusted:true and the description states their trust level.
- content_post_preview uses an injected extracted admin renderer, includes drafts and pending
  body/template edits, requires content.read, and returns the shared page shape without post writes.
  The route preserves auth, GET/POST override semantics, cache headers and state-conflict statuses.
- Both new tools are independently classified none/readOnly and wired in distinct catalog domains.
  Search vocabulary and 4–6 doc2query phrases per tool are installed and tested through the full
  production registry and real SQLite search; all twelve task-specific phrases rank in the top 3.
