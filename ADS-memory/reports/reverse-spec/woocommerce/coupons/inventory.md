## Domain Model

### Entity: WC_Coupon

**Source:** `includes/class-wc-coupon.php`

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| code | string | '' | Case-insensitive (stored lowercase via `wc_format_coupon_code`) |
| amount | decimal | 0 | Non-negative. Percent type capped at 100. |
| status | string | null | WordPress post status (publish, draft, trash) |
| date_created | datetime | null | |
| date_modified | datetime | null | |
| date_expires | datetime | null | Coupon invalid after this timestamp |
| discount_type | enum | 'fixed_cart' | One of: percent, fixed_cart, fixed_product |
| description | string | '' | |
| usage_count | int | 0 | Global usage counter |
| individual_use | bool | false | Cannot combine with other coupons |
| product_ids | int[] | [] | Whitelist — coupon only applies to these products |
| excluded_product_ids | int[] | [] | Blacklist — coupon never applies to these |
| usage_limit | int | 0 | 0 = unlimited global uses |
| usage_limit_per_user | int | 0 | 0 = unlimited per-user uses |
| limit_usage_to_x_items | int|null | null | Cap discount to N items |
| free_shipping | bool | false | Grants free shipping when valid |
| product_categories | int[] | [] | Category whitelist |
| excluded_product_categories | int[] | [] | Category blacklist |
| exclude_sale_items | bool | false | Skip items already on sale |
| minimum_amount | decimal | '' | Minimum cart subtotal required |
| maximum_amount | decimal | '' | Maximum cart subtotal allowed |
| email_restrictions | string[] | [] | Allowed customer emails (supports wildcards) |
| used_by | array | null | Lazy-loaded list of user IDs / emails who used it |
| virtual | bool | false | True = programmatic coupon not stored in DB |

### Discount Types

| Key | Behavior |
|-----|----------|
| `percent` | `amount`% off each eligible item (capped at item price) |
| `fixed_cart` | `amount` distributed proportionally across eligible items by price share of subtotal |
| `fixed_product` | `amount` off per eligible item unit (capped at item price) |
