# Merge-7 persisted-data cutover

Bases verified at Tovu `8d1a4c2742` and Jini `06559affb`. The upgrade has two separate failure points. A saved embed carries the publisher-qualified ID, while an Agent Plugin’s package slot and enablement record use its short name. An old bundled revision can also block installation of the new revision in that same slot. Both must be handled before an existing site can render the migrated embed.
